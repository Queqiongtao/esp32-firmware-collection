# 流体效果方案设计

最后更新：2026-08-01

本文是流体效果的目标蓝图，当前处于**设计讨论阶段**，所有条目均为待确认方向，不作为已实现承诺。随讨论推进逐步收敛，最终方案落定后在本文件标记为“已定案”并进入实现。

## 1. 目标与形态定义

“流体效果”先要定义具体形态。候选方向（互斥或可组合）：

| 形态 | 描述 | 实现难度 | 适合场景 |
| --- | --- | --- | --- |
| A. 波纹/涟漪 | 触摸落点产生水面涟漪，随时间扩散衰减 | 低（2D 波动方程，小网格） | 交互反馈、壁纸 |
| B. Metaball 液态 | 手指拖动粘性液滴（经典 metaball 场函数 + 平滑），流动感强 | 中 | 主推候选 |
| C. 简化流体模拟 | Stable Fluids / 格子玻尔兹曼式密度-速度场，触摸为外力源 | 中高 | 真实流体感 |
| D. 流动粒子 | 粒子在速度场中流动（如熔岩灯/烟雾/星云） | 中 | 氛围效果 |

## 2. 平台约束（决定实现路线）

| 约束 | 影响 |
| --- | --- |
| ESP32-S3 **无硬件浮点单元**（LX7 双核 240 MHz） | 模拟计算须用定点数或查表；全屏逐像素浮点不可行 |
| QSPI 40 MHz，理论 20 MB/s | 整帧 322 KiB 理论 ~60 FPS，实际建议按 30-50 FPS 规划 |
| PSRAM 充足（可用 `MALLOC_CAP_SPIRAM` 整帧缓冲） | 双缓冲、模拟网格数组均可放 PSRAM |
| 无 GPU，纯 CPU 渲染 | 渲染分辨率必须降采样或分块 |
| AMOLED | 纯黑像素不耗电，适合深色背景 + 高亮流体；避免长时间高亮静态画面（烧屏风险） |

## 3. 初步实现路线（待讨论确认）

1. **模拟网格降采样**：例如 1/4 屏（92x112）或 1/2 屏（184x224）网格，模拟步进 30-60 Hz
2. **双核分工**：模拟任务跑一个核，渲染+提交跑另一个核；通过环形缓冲/信号量交接
3. **双缓冲 + 局部刷新**：ping-pong 帧缓冲，按脏区 `draw_bitmap` 局部提交；需要时接入 TE 同步
4. **触摸注入**：press 产生源项（密度+速度脉冲），move 产生拖拽力，up 停止
5. **字节序封装**：先实测 RGB565 字节序，统一颜色宏，再写任何绘制代码

## 4. 待讨论问题清单

- 形态选型：A/B/C/D 哪个（或组合）？
- 用途：纯壁纸氛围、触摸交互玩具、还是将来接业务界面背景？
- 目标帧率与网格分辨率（30 FPS @ 1/4 屏 还是 60 FPS @ 更小网格？）
- 配色与亮度策略（深色底 + 高亮流体？需要几个预设主题？）
- 是否需要双指/多点（当前驱动只读单点）
- 是否需要屏幕熄屏/低功耗模式（AMOLED 息屏省电）
- 效果是否随时间渐变（昼夜、情绪）或保持稳定

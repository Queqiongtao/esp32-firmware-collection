## 二、主题预览工具

### 目录结构

```
tools/preview/
├── CMakeLists.txt   # 通过 LVGL 自带 os_desktop.cmake 构建主机库
├── lv_conf.h        # RGB565 / Montserrat 12~40 / SNAPSHOT·SCALE·CANVAS·ARC
├── preview.cpp      # 虚拟 466x466 display → 逐主题 build/update/tick → 快照
├── render.py        # PPM→PNG、圆屏遮罩、对比图、越界报告
├── run.sh           # 一键构建 + 渲染
├── README.md
└── out/             # 产物，已 gitignore
```

### 用法

```bash
./tools/preview/run.sh
./tools/preview/run.sh --time 23:59:59
```

### 产物

| 路径 | 说明 |
|------|------|
| `out/r1.0/*.png` | 单主题图，叠加圆屏遮罩与玻璃边缘 |
| `out/raw/*.png` | 未遮罩原图 |
| `out/contact_native.png` | 4 个原生主题对比图 |
| `out/contact_m5.png` | 4 个 M5 主题对比图 |
| `out/contact_all.png` | 8 主题总览 |
| `out/report.txt` | 非黑像素范围与安全区越界告警 |

### 关键实现点

1. LVGL 9.4.0 使用官方 `env_support/cmake/os_desktop.cmake` 编译。
2. 快照对象是 `lv_screen_active()`，不是主题根，确保 M5 Simple 的秒点覆盖层被渲染。
3. 固定时间渲染，`--time` 可指定；默认渲染 `10:08:35` 与 `23:59:59` 两个时刻。
4. 主题 `tick()` 被推进到结束状态，保证截图稳定。

### 已知局限

- 无面板 Gamma/亮度，颜色略生硬。
- 无 PSRAM/刷新时序，无法验证流畅度与内存。
- 不包含 snapshot 旋转逻辑。

## 四、逐主题设计稿

### 1. minimal（✅ 已完成，待上板确认）

**概念：黑曜石极简**

- 根容器 466x466 纯黑，走 466 快照快路径
- `HH:MM` 使用新字体 `lv_font_clock_144`：数字高 104px，整行宽约 365px，占屏宽 78%
- 时间居中于 y=200
- 信息行居中于 y=305：`TUE 20 OCT` 20px 灰 `#9AA0A6`、字距 2；3px 强调色圆点分隔；秒数 20px 强调色
- 外圈三层结构：
  - 3px 秒进度弧：轨道 `#232323`，进度色随分钟轮换，12 点起顺时针
  - 1px 内侧细环：412px，r=206，`#2A2A2A`
  - 轨道珠：10px 强调色圆 + 14px 黑色遮罩，中心落在弧线半径 r≈216.5，形成 2px 黑色间隙
- 强调色每分钟轮换一次（秒弧走满一圈时切换），8 色盘：
  `#FF9F0A` 橙、`#FF6B4A` 珊瑚、`#FF4D8D` 玫红、`#D96BFF` 兰紫、
  `#8B7BFF` 紫蓝、`#4D9DFF` 蓝、`#2FD6D0` 青、`#6BE3A8` 薄荷
- 取色规则 `tm_min % 8`；秒弧、轨道珠、秒数、信息行圆点同步变色，时间、日期、细环和轨道保持中性
- 垂直内容块约 148–317，中心与屏幕中心基本重合

实现要点：

- 弧：`lv_arc_set_bg_angles(arc, 0, 360)` + `lv_arc_set_rotation(arc, 270)` + `range 0..60`
- 调色盘为静态 `uint32_t` 数组；只有颜色真正变化时才调用 `lv_obj_set_style_*`，避免每秒无意义重绘
- 主题重建时会把颜色缓存清零，确保切回 minimal 后立即应用当前分钟的颜色
- 轨道珠每秒按 `-90° + sec * 6°` 计算位置，用 `lv_obj_align()` 移动到半径 216.5 处
- 黑色遮罩会切断珠子和弧线之间的连接，形成"珠子套在轨道上"的立体感
- 秒数从时间行移到信息行后，主行只有一个焦点，字号才能放到 144
- 每秒只调用 `lv_arc_set_value()`、三个 label 的文本更新、一次珠子定位和必要的换色，不新增 `tick()`，快照仍为 1 Hz
- 换色是瞬时切换：当前快照每秒一张，做渐变得把快照提到 30fps，成本和收益不匹配
- 字体生成命令与 `lv_font_clock_96` 一致，只改字号：

```bash
npx lv_font_conv --font /usr/share/fonts/truetype/ubuntu/Ubuntu-M.ttf \
  --size 144 --bpp 4 --range 0x30-0x3A --format lvgl --no-compress \
  --lv-include lvgl.h -o main/lv_font_clock_144.c
```

- 新字体同时加入 `main/CMakeLists.txt` 和 `tools/preview/CMakeLists.txt`
- 预览 `report.txt` 中 minimal 最大半径约 222，来自轨道珠，仍在圆屏半径 233 以内；0 秒和 59 秒边界位置单独渲染确认过
- 额外渲染 10:08–10:15 八个分钟，确认 8 个强调色都能在黑色背景上分辨
- 144 字体源文件约 208KB；由于 minimal 不再引用 96 字体，链接后固件净增约 19KB

### 2. segment

**概念：赛博终端**

- 修复顶部装饰线越界（改为圆内弦长安全的短线，或删除）
- 幽灵数字改为与实际文本同宽（或降低不透明度/去除）
- 底部秒与日期改居中对称布局，同一基线
- 减少装饰文字：只保留一个顶部小标题
- 增加秒进度条与 HUD 角括号
- 清理未使用的颜色宏

### 3. analog

**概念：机械计时**

- 补日期：3 点钟位置双行（`TUE` + `20`）+ 凹陷日期窗
- 6 点钟小秒盘
- 多层表圈与立体时刻度
- 三层中心轴

### 4. outline

**概念：线框轨道**

- 多同心细环
- 低透明放射刻度（sunburst）
- 红色秒点沿表圈运行
- 空心中心
- 6 点钟日期
- 去掉纯黑底上无意义的黑描边层

### 5. M5 四主题（暂停）

- `m5_classic`：星期颜色对比度偏低，日期胶囊偏紧
- `m5_simple`：暂无硬伤
- `m5_big_number`：无日期，留白大
- `m5_number_flow`：面板无 H/M/S 标识
- 待 4 个原生主题完成后讨论：保持还原度 or 允许重设计

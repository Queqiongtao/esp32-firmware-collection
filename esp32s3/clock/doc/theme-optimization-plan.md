## 二、主题预览工具

### 目录结构

```
tools/preview/
├── CMakeLists.txt   # 通过 LVGL 自带 os_desktop.cmake 构建主机库
├── lv_conf.h        # RGB565 / Montserrat 12~40 / SNAPSHOT·SCALE·CANVAS·ARC
├── preview.cpp      # 虚拟 466x466 display → 逐主题 build/update/tick → 快照
├── render.py        # PPM→PNG、圆屏遮罩、对比图、越界报告
├── run.sh           # 一键构建 + 渲染
├── README.md
└── out/             # 产物，已 gitignore
```

### 用法

```bash
./tools/preview/run.sh
./tools/preview/run.sh --time 23:59:59
```

### 产物

| 路径 | 说明 |
|------|------|
| `out/r1.0/*.png` | 单主题图，叠加圆屏遮罩与玻璃边缘 |
| `out/raw/*.png` | 未遮罩原图 |
| `out/contact_native.png` | 4 个原生主题对比图 |
| `out/contact_m5.png` | 4 个 M5 主题对比图 |
| `out/contact_all.png` | 8 主题总览 |
| `out/report.txt` | 非黑像素范围与安全区越界告警 |

### 关键实现点

1. LVGL 9.4.0 使用官方 `env_support/cmake/os_desktop.cmake` 编译。
2. 快照对象是 `lv_screen_active()`，不是主题根，确保 M5 Simple 的秒点覆盖层被渲染。
3. 固定时间渲染，`--time` 可指定；默认渲染 `10:08:35` 与 `23:59:59` 两个时刻。
4. 主题 `tick()` 被推进到结束状态，保证截图稳定。

### 已知局限

- 无面板 Gamma/亮度，颜色略生硬。
- 无 PSRAM/刷新时序，无法验证流畅度与内存。
- 不包含 snapshot 旋转逻辑。

### 视觉问题

- **minimal**：三行竖排层级平均，像秒表；日期 `TUE 10-20` 有歧义；画面空。
- **segment**：幽灵数字 `88:88` 比实际时间宽，左右漏出像重影；顶部亮线被圆屏裁切；底部左右不对称。
- **analog**：只有刻度与指针，缺日期，盘面空。
- **outline**：与 analog 构造几乎相同，辨识度不足。

## 四、逐主题设计稿

### 1. minimal

**概念：黑曜石极简**

- 根容器 466x466 纯黑
- `HH:MM` 96px 白色，主视觉
- 秒改为行内小号：26px 橙色 `#FF9F0A`，贴时间右下、基线对齐
- 日期 `TUE 20 OCT`，20px、字距 3、灰 `#9AA0A6`
- 外圈 2px 秒进度弧：轨道 `#1A1A1A`，进度橙色，从 12 点顺时针
- 1px 极淡圆环（半径 212）压住构图

### 2. segment

**概念：赛博终端**

- 修复顶部装饰线越界（改为圆内弦长安全的短线，或删除）
- 幽灵数字改为与实际文本同宽（或降低不透明度/去除）
- 底部秒与日期改居中对称布局，同一基线
- 减少装饰文字：只保留一个顶部小标题
- 增加秒进度条与 HUD 角括号
- 清理未使用的颜色宏

### 3. analog

**概念：机械计时**

- 补日期：3 点钟位置双行（`TUE` + `20`）+ 凹陷日期窗
- 6 点钟小秒盘
- 多层表圈与立体时刻度
- 三层中心轴

### 4. outline

**概念：线框轨道**

- 多同心细环
- 低透明放射刻度（sunburst）
- 红色秒点沿表圈运行
- 空心中心
- 6 点钟日期
- 去掉纯黑底上无意义的黑描边层

### 5. M5 四主题（暂停）

- `m5_classic`：星期颜色对比度偏低，日期胶囊偏紧
- `m5_simple`：暂无硬伤
- `m5_big_number`：无日期，留白大
- `m5_number_flow`：面板无 H/M/S 标识
- 待 4 个原生主题完成后讨论：保持还原度 or 允许重设计

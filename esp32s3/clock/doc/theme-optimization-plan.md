## 二、主题预览工具

### 目录结构

```
tools/preview/
├── CMakeLists.txt   # 通过 LVGL 自带 os_desktop.cmake 构建主机库
├── lv_conf.h        # RGB565 / Montserrat 12~40 / SNAPSHOT·SCALE·CANVAS·ARC
├── preview.cpp      # 虚拟 466x466 display → 逐主题 build/update/tick → 快照
├── render.py        # PPM→PNG、圆屏遮罩、对比图、越界报告
├── run.sh           # 一键构建 + 渲染
├── README.md
└── out/             # 产物，已 gitignore
```

### 用法

```bash
./tools/preview/run.sh
./tools/preview/run.sh --time 23:59:59
```

### 产物

| 路径 | 说明 |
|------|------|
| `out/round/*.png` | **默认查看**：单主题圆屏图，圆外中灰 + 亮灰玻璃边缘 |
| `out/raw/*.png` | 未遮罩方图，仅调试构图用 |
| `out/ppm/*.ppm` | 原始渲染 PPM |
| `out/contact_native.png` | 4 个原生主题圆屏对比图 |
| `out/contact_m5.png` | 4 个 M5 主题圆屏对比图 |
| `out/contact_all.png` | 8 主题圆屏总览 |
| `out/report.txt` | 非黑像素范围与安全区越界告警 |

### 关键实现点

1. LVGL 9.4.0 使用官方 `env_support/cmake/os_desktop.cmake` 编译。
2. 快照对象是 `lv_screen_active()`，不是主题根，确保 M5 Simple 的秒点覆盖层被渲染。
3. 固定时间渲染，`--time` 可指定；默认渲染 `10:08:35` 与 `23:59:35` 两个时刻。
4. 主题 `tick()` 被推进到结束状态，保证截图稳定。
5. 圆屏预览是默认产物：圆外填中灰 `#262626`，边缘画 2px 亮灰 `#7A7A7A`，避免和主题黑底混在一起；方图只作为调试用。

### 已知局限

- 无面板 Gamma/亮度，颜色略生硬。
- 无 PSRAM/刷新时序，无法验证流畅度与内存。
- 不包含 snapshot 旋转逻辑。

## 四、逐主题设计稿

### 1. minimal（✅ 已完成，待上板确认）

**概念：黑曜石极简**

- 根容器 466x466 纯黑，走 466 快照快路径
- `HH:MM` 使用新字体 `lv_font_clock_144`：数字高 104px，整行宽约 365px，占屏宽 78%
- 时间居中于 y=200
- 信息行居中于 y=305：`TUE 20 OCT` 20px 灰 `#9AA0A6`、字距 2；3px 强调色圆点分隔；秒数 20px 强调色
- 外圈三层结构：
  - 3px 秒进度弧：轨道 `#232323`，进度色随分钟轮换，12 点起顺时针
  - 1px 内侧细环：412px，r=206，`#2A2A2A`
  - 轨道珠：10px 强调色圆 + 14px 黑色遮罩，中心落在弧线半径 r≈216.5，形成 2px 黑色间隙
- 强调色每分钟轮换一次（秒弧走满一圈时切换），8 色盘：
  `#FF9F0A` 橙、`#FF6B4A` 珊瑚、`#FF4D8D` 玫红、`#D96BFF` 兰紫、
  `#8B7BFF` 紫蓝、`#4D9DFF` 蓝、`#2FD6D0` 青、`#6BE3A8` 薄荷
- 取色规则 `tm_min % 8`；秒弧、轨道珠、秒数、信息行圆点同步变色，时间、日期、细环和轨道保持中性
- 垂直内容块约 148–317，中心与屏幕中心基本重合

实现要点：

- 弧：`lv_arc_set_bg_angles(arc, 0, 360)` + `lv_arc_set_rotation(arc, 270)` + `range 0..60`
- 调色盘为静态 `uint32_t` 数组；只有颜色真正变化时才调用 `lv_obj_set_style_*`，避免每秒无意义重绘
- 主题重建时会把颜色缓存清零，确保切回 minimal 后立即应用当前分钟的颜色
- 轨道珠每秒按 `-90° + sec * 6°` 计算位置，用 `lv_obj_align()` 移动到半径 216.5 处
- 黑色遮罩会切断珠子和弧线之间的连接，形成"珠子套在轨道上"的立体感
- 秒数从时间行移到信息行后，主行只有一个焦点，字号才能放到 144
- 每秒只调用 `lv_arc_set_value()`、三个 label 的文本更新、一次珠子定位和必要的换色，不新增 `tick()`，快照仍为 1 Hz
- 换色是瞬时切换：当前快照每秒一张，做渐变得把快照提到 30fps，成本和收益不匹配
- 字体生成命令与 `lv_font_clock_96` 一致，只改字号：

```bash
npx lv_font_conv --font /usr/share/fonts/truetype/ubuntu/Ubuntu-M.ttf \
  --size 144 --bpp 4 --range 0x30-0x3A --format lvgl --no-compress \
  --lv-include lvgl.h -o main/lv_font_clock_144.c
```

- 新字体同时加入 `main/CMakeLists.txt` 和 `tools/preview/CMakeLists.txt`
- 预览 `report.txt` 中 minimal 最大半径约 222，来自轨道珠，仍在圆屏半径 233 以内；0 秒和 59 秒边界位置单独渲染确认过
- 额外渲染 10:08–10:15 八个分钟，确认 8 个强调色都能在黑色背景上分辨
- 144 字体源文件约 208KB；由于 minimal 不再引用 96 字体，链接后固件净增约 19KB

### 2. segment（🟨 预览待确认）

**概念：Amber Deck**

- 放弃青色 HUD、幽灵数字、角括号和装饰刻度，改成暖色仪表盘
- 左上角 `● SEGMENT` 小标题：7px 珊瑚圆点 + 12px 暗琥珀 `#B87800`，字距 3，位于 (64, 90)
- 中央 338×116 深琥珀面板：底色 `#160E05`、2px 边框 `#5A360C`、圆角 16，位于 (64, 130)
- `HH:MM` 使用 96px 七段字体，琥珀 `#FFB000`，在面板内居中；去掉幽灵底字
- 左下日期 `TUE 20 OCT`：24px 奶油色 `#FFE7C2`，位于 (64, 292)
- 右下 72×48 珊瑚秒牌：底色 `#FF5C35`、圆角 10，位于 (330, 284)，36px 七段数字用纯黑
- 底部 338×6 秒进度条：轨道 `#3A1A0A`、填充 `#FF5C35`，圆角 3，位于 (64, 372)，宽度按 `338 * sec / 60` 增长
- 仅使用现有字体 `lv_font_seg_96`、`lv_font_seg_36`、`lv_font_montserrat_24`、`lv_font_montserrat_12`，不新增 CMake 源文件

预览结果：

- `report.txt` 中 segment 最大半径 221.4，来自左上标题；圆屏半径 233，圆内余量约 11.6px
- 报告仍会提示“超出安全区”，因为预览工具的安全线是 205；m5_classic（225.2）同样提示，不代表圆屏裁切
- 0 秒和 59 秒边界单独渲染确认：0 秒进度条只剩暗色轨道、秒牌显示黑色 `00`；59 秒进度条接近满格、秒牌显示 `59`
- 时间行在 338px 面板内左右各留约 10px，没有贴边或裁切
- `./dev.sh build` 通过；`esp-clock.bin` = 0x15bbf0，6 MB 分区剩余 77%
- 面板边框、琥珀色和黑底珊瑚秒牌在真实 AMOLED 上的亮度/对比度需上板确认

实现要点：

- 删除 `make_seg_field()`、`make_corner()` 和全部 HUD 装饰函数，主题只保留盒子、标签两套基础构造
- 秒牌先建珊瑚色圆角盒子，再把黑色七段标签居中放入，避免给文字加底色
- 进度条轨道和填充都用同高圆角盒子，填充宽度每秒更新；0 秒时宽度为 0
- `segment_update()` 每秒更新 `HH:MM`、秒数、日期和进度宽度，没有额外定时器，快照仍为 1 Hz

### 3. analog（✅ 已完成，待上板确认）

**概念：机械计时**

- 466 根容器纯黑；三层表圈：458px 外缘 `#2A2A2A`、446px 亮色倒角 `#565656`、432px 内圈 `#1F1F1F`
- 426px 分钟轨道：60 个细刻度 + 12 个略长的小时刻度，灰 `#7A7A7A` / `#B8B8B8`
- 396px 立体时标：12 个 7×15 圆角米白刻度 `#EDE9DF`，与分钟轨道分层
- 3 点钟日期窗：82×62 深灰外框 + 74×54 内窗，`TUE` 12px 灰、`20` 28px 奶油 `#F0E6D2`
- 6 点钟小秒盘：112px 外框 + 104px 内窗 + 100px 分钟刻度盘，红色小秒针带短尾针，中心双层轴
- 主指针：时针 112px、分针 150px，米白 `#F3EFE5` + 黑色描边；取消中央秒针，秒数只在 6 点小秒盘显示
- 三层中心轴：30px 深灰基座 + 20px 米白轴 + 8px 红色轴心
- 12 点下方加 `MECHANICAL` 12px 深灰字，字距 3，补足上半盘留白
- 仅使用现有 Montserrat 字体，不新增 CMake 源文件

预览结果：

- `report.txt` 中 analog 最大半径 229.8，来自 458px 外圈；圆屏半径 233，圆内余量约 3.2px
- 报告仍提示“超出安全区”，是预览安全线 205 的规则，不代表圆屏裁切
- 额外渲染 `00:00:59`、`03:00:00`、`12:00:00`：12 点两针重合正常；3 点时针压到日期窗左边缘，但未遮住 `TUE 20`；小秒盘在 0/59 秒边界正常
- `./dev.sh build` 通过；`esp-clock.bin` = 0x15c060，6 MB 分区剩余 77%
- 深灰表圈、米白指针和红色小秒针在真实 AMOLED 上的亮度/对比度需上板确认

实现要点：

- 分钟刻度与立体时标使用两个独立 `lv_scale`，避免长刻度和大时标互相覆盖
- 时标 scale 使用 13 个 tick（含首尾重叠的 12 点）得到 12 个 30° 分布位置
- 日期窗和小秒盘先于主指针创建，指针自然压在窗口上方，保留机械表层次
- 小时针角度加入秒数微调 `sec / 12`，走时更顺滑
- `analog_update()` 每秒更新时针、分针、小秒针和日期文本，无额外定时器

### 4. outline（✅ 已完成，待上板确认）

**概念：线框轨道**

- 466 根容器纯黑，冷灰蓝线框配色，和 analog 的暖米白机械盘区分
- 四层同心细环：458px 外缘 `#2E3A40`、430px 主环 `#52666F`、398px 中环 `#263238`、356px 内环 `#1B2428`
- 430px 太阳放射刻度：121 个 1px 短线、3° 间隔、长 18px、低对比 `#2B373C`
- 430px 分钟轨道叠加 60 个短刻度，5 分钟刻度略亮
- 380px 小时标记：12 个 2×10 冷灰刻度，补足读时
- 红色秒点：半径 206px，12px 黑色遮罩 + 8px 红点，每秒沿表圈跳动
- 6 点钟日期环：104px 细环，`TUE` 12px 冷灰 + `20 OCT` 20px 冰白
- 主指针：时针 110px×5、分针 152px×3，冰白 `#E6F1F5`，去掉纯黑底上无效的黑色描边
- 空心中心：18px 与 8px 两层细环，指针在环内交汇
- 不新增字体或 CMake 源文件

预览结果：

- `report.txt` 中 outline 最大半径 229.9，来自 458px 外圈；圆屏半径 233，圆内余量约 3.1px
- 报告提示“超出安全区”是预览安全线 205 的规则，不代表圆屏裁切
- 额外渲染 `00:00:00`、`00:00:59`、`06:00:00`、`12:00:00`：红色秒点在 0/59 秒位置正常；12 点两针重合正常；6 点两针会压住日期环，属于实体表指针遮挡，按机械表特性保留
- `./dev.sh build` 通过；`esp-clock.bin` = 0x15c240，6 MB 分区剩余 77%
- 放射刻度对比度较低，真实 AMOLED 上可能更暗，需上板确认

实现要点：

- 太阳放射、分钟刻度、小时标记使用三个独立 `lv_scale`，分别控制长度、宽度和明暗
- 秒点用圆形黑色遮罩包住红点，避免和同心环粘连
- 日期环先于指针创建，保留“指针在表盘上方”的机械层次
- 小时针角度加入秒数微调 `sec / 12`，分针按秒连续移动
- `outline_analog_update()` 每秒更新两针、日期和秒点位置，无额外定时器

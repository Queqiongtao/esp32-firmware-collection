# Clock 体验优化记录

## 目标与改动

本轮面向随身把玩与展示，保留八个主题的顺序、特色和英文界面，沿用已有 ESP-IDF、LVGL 和 RGB565 snapshot 架构。

| 批次 | 已实现行为 |
| --- | --- |
| 表盘与切换 | 八个表盘恢复本轮优化前的布局、配色、字号及各自日期格式；保留 Display → Watch faces 两页圆形小预览，选中后点 Apply 应用；切换期间隐藏独立秒点，结束后恢复 |
| 菜单与操作 | 主操作按钮至少 44 px、辅助文字至少 14 px；Sound 内容独立滚动；闹钟逐分钟调整和长按连调；扫描期间可返回/关闭/息屏，提供 Rescan、无结果及错误反馈 |
| 业务可靠性 | 按日期/槽位去重并排队；各槽位独立 Snooze；闹钟结束后补发倒计时完成提醒；提醒优先于普通音效，白噪音被打断后手动重启；整点报时按日期和小时去重 |

菜单及配网、详情弹层均遵循一分钟无操作关闭。Sound 总开关控制普通音效、计时和白噪音，闹钟保留独立响铃路径；Sound 页明确提示此关系。白噪音缺少 USB 或 Sound 关闭时显示原因并禁用 Start。

## 接口与资源维护

- `clock_settings_menu_config_t` 增加主题目录、选择回调及扫描结果读取回调；菜单只在 LVGL 线程内创建、更新和删除对象。
- `wifi_manager_scan_start()` 非阻塞启动；`wifi_manager_scan_results()` 返回 idle/busy/done/error 和结果副本。SCAN_DONE 事件只发布状态；应用侧轮询完成 AP 列表回收和临时射频状态恢复，15 秒超时也执行清理。
- 扫描中关闭 WiFi 会立即保存关闭意图，扫描完成后关闭射频；扫描中开启 WiFi 或保存连接请求返回忙碌，不修改已保存凭据。退出扫描页面只取消 UI 对结果的关注，底层清理由网络状态轮询继续完成。
- 八张 88×88 RGB565 小预览占 123,904 字节静态图片数据，位于 flash；选择器每页显示四张，不同时创建八个主题，也不增加整屏 snapshot 缓冲。
- 缩略图点击仅改变临时候选高亮，翻页保留候选；Apply 才触发原有切换与保存流程，同一主题时禁用。Back、超时、息屏或物理键关闭会丢弃候选，重新打开恢复实际主题；确认期间屏蔽重复提交。
- 主题顺序与 NVS 格式保持原样。新增主题时同步固件/主机主题列表、`generate_thumbnails.py` 的 FACES 和小预览声明。

主题视觉修改后运行：

```bash
./tools/preview/run.sh
python3 tools/preview/generate_thumbnails.py
./tools/preview/run.sh
./dev.sh build
```

普通预览不改写跟踪资源；只有显式运行生成器才更新 `main/clock_theme_previews.c`。

本轮表盘视觉精修已按用户要求回退；小预览同步按恢复后的主题重新生成，菜单入口卡片、圆形裁切和 Apply 确认流程继续保留。

## 提醒调度约定

- 每次轮询都收集当前分钟的所有到期闹钟，包括正在响铃时；按槽位顺序依次展示。
- 停止或 60 秒超时会结束当前闹钟；一次性闹钟同时关闭。Snooze 保留该槽位的五分钟单调时间截止点，并释放显示/音频给其他提醒。
- 普通倒计时结束会保留一个待提醒事件；闹钟释放后只补发一次。若倒计时弹窗被新闹钟抢占，其完成事件也会保留到闹钟结束。
- 日期采用每槽位的触发日期高水位：校时回拨不重放历史日期，前跳跨过的时刻不补响。用户修改时间、星期或开关时重新启用该槽位；仅更换音色不重放已收集的事件。
- 去重、Snooze 和排队状态保存在运行内存中；重启后不恢复进行中的提醒。倒计时及 Snooze 使用单调时间，不受 NTP 校时影响。
- 闹钟优先于倒计时完成提示；冲突的 UI 音效、报时跳过。计时弹窗的 OK 或 PWR 会同时停止提示音。白噪音被闹钟或倒计时提示打断后不自动恢复。

## 主机验证

```bash
cmake -S tools/preview -B tools/preview/build -DCMAKE_BUILD_TYPE=Release
cmake --build tools/preview/build -j8
ctest --test-dir tools/preview/build --output-on-failure
```

- `alert_scheduler`：跨日同时间、星期、并发队列、各槽位 Snooze、禁用/编辑、倒计时优先级、时钟前跳/回拨及 60 秒超时。
- `menu_and_themes`：表盘分页/选择、扫描重复请求/返回/菜单销毁/空结果/失败、Sound 滚动和弹层、分钟调整、八主题午夜日期更新。
- 压力测试先预热完整的 120 次主题与时刻组合，再测量 240 次重复切换；每次复用快照并检查销毁后没有遗留屏幕子对象，同时比较相同序列边界的主机堆用量，避免把字体缓存和分配器波动误判为持续泄漏。
- 默认输出 16 张主题图和 24 张菜单状态图，包含候选选中且 Apply 可用的状态；边界时刻另用 `preview --themes-only --time HH:MM:SS` 追加，`report.txt` 的安全区提示需要结合圆屏图判断。
- CTest 仅对 UI 测试进程关闭 glibc 线程分配缓存，避免 `mallinfo2()` 将已释放但被缓存的块计入占用；固件内存配置不受影响。

## 真机验收

当前环境 `./dev.sh ports` 未发现串口，未刷机。主机测试与编译结果不能替代以下验收：

1. 八主题颜色、亮度、数字间距和小字号在 AMOLED 上清晰；缩略图只选中，Apply 后切换且重启恢复正确；翻页保留候选，取消/关闭后主题不变。
2. 连续滑动至少 200 次不丢步、不误开菜单；旋转中切换无旧图/秒点残留，对比原固件的过渡耗时、刷新与空闲内存。
3. Sound 滚动、音量拖动、底部 Tab、长按连调、菜单一分钟超时及唤醒首触不穿透。
4. 扫描期间退出菜单、息屏和关闭 WiFi；扫描完成/失败后射频恢复正确；重新进入不展示过期页面或结果。验证真实 AP、断线退避及现有 NTP 修改。
5. 三闹钟同分钟到期、响铃 60 秒、逐个 Snooze/Stop、响铃中倒计时到期及计时弹窗被闹钟抢占；检查弹窗和声音的先后顺序。
6. Sound 关闭时闹钟仍响，计时只显示提示；白噪音只在 USB 且 Sound 开启时启动，拔掉 USB 或被提醒打断后停止。

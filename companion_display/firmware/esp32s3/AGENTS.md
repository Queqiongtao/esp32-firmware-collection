# 仓库协作规则

## 语言

- 面向用户的全部对话回复必须使用中文。
- 用户文档使用中文；命令、代码标识、协议常量和 JSON 字段保持其原始拼写。

## 文档同步

- 修改通信协议、控制消息、帧格式、端口、超时、状态码、错误码、传输行为或安全边界时，必须同步更新 `../../PROTOCOL.md`。
- 修改构建、烧录、配置、使用流程、PC 客户端界面或故障排查方式时，必须同步更新 `README.md`。
- 实现与文档不一致时，交付前必须修正文档或实现；提交前检查字段名、默认值、链接和示例命令。

## 变更原则

- 保持 TCP 控制通道与 UDP 视频通道的职责分离，未经协议版本升级不得破坏现有 v1 互操作性。
- 新增触摸、文字或音频能力时，先在 `../../PROTOCOL.md` 定义消息、鉴权、生命周期、失败处理和兼容策略，再实现两端代码。

# P4 主题适配说明

## 设计坐标系

S3 工程的 8 个主题和菜单以 466×466 为设计网格。P4 面板为 800×800，直接重写所有主题坐标成本高且容易引入回归，因此采用“设计网格 + 编译期换算”：

- `clock_theme_px(v)`：把 466 网格的整数像素换算为 800 网格，负值四舍五入。
- `clock_theme_pxf(v)`：浮点版本，用于半径、角度相关布局。
- 字号不通过换算函数缩放，而是重新生成对应大小的位图字体，保证文字在 800 下原生清晰。

这种方式不会产生父容器放大后的模糊，所有对象仍由 LVGL 在 800×800 上直接绘制。

| m5_big_number | 数字图片按 439/256 缩放，位置和日期同步放大 |

| dot_matrix | 7 px 圆点、10 px 节距、主 canvas 647×247、秒数 canvas 107×67 |

## 已知取舍

- M5 手型和 Big Number 数字沿用 466 资源，运行时图片缩放；文字和点阵已按 800 重新生成。若后续追求极致锐度，可从原始 PNG/TTF 重新生成 800 资源。
- 部分装饰（analog 表圈、m5_classic 刻度）接近 400 px 圆屏边缘，预览会提示“超出安全区”，属于预期。
- `clock_theme_px()` 只用于布局；颜色、透明度、动画时长、角度值不换算。

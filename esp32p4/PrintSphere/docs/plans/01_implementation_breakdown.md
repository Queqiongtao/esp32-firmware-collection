# 详细实施计划

## WP1 工程与工具链

- [x] 创建独立 ESP-IDF 工程并固定 `IDF_TARGET=esp32p4`。
- [x] 固定 IDF `6.0.1`、LVGL `9.5.0` 及 managed components。
- [x] 处理 IDF 6.0.1 `periph_ctrl.h` 的 `stdbool.h` 兼容问题。
- [x] 保持业务代码 C++17，替换 C++20 专用 API。

- [ ] 在干净依赖缓存环境执行一次依赖解析和构建复现。

## WP2 板级支持

- [x] 导入 JD9165 MIPI DSI 驱动与 1024x600 时序。
- [x] 建立共享 I2C1，接入 GT911 和 ES8311。
- [x] 接入背光、0°/180°显示与 LVGL 自动触摸变换；显示配置和锁超时已贯通 BSP。
- [x] 接入 ESP32-C6 Hosted，并在继续 Wi-Fi 初始化前等待 transport ready。
- [x] 用 GPIO52 / ADC2 Channel 3 替换 S3 PMU。
- [ ] 上板校验各引脚、复位时序和失败恢复。
- [ ] 实测电池分压、空载噪声和 3.3/4.2 V 映射。

- [x] 页面和滑页视口改为 1024x600。
- [x] 打印机选择页改为宽列表。
- [x] 仪表页代码改为左状态、右指标布局，状态环归属主仪表页且不跨页覆盖。

- [x] Web Config 和持久化层限制为 0°/180°。
- [ ] 上板逐页检查文字长度、图像比例、动画和触摸命中区。

# JC1060P470 硬件适配

## 核心资源

| 子系统 | 配置 |
| --- | --- |
| SoC | ESP32-P4 V1.0，Hex PSRAM 200 MHz，16 MiB Flash |
| LCD | JD9165，1024x600 RGB565，MIPI DSI 2 lane |
| DSI | lane 600 Mbps，DPI clock 54 MHz，双 framebuffer |
| DPHY 电源 | 内部 LDO channel 3，2.5 V |
| 触摸 | GT911，原生坐标 800x480，映射到 1024x600 |
| Wi-Fi | 板载 ESP32-C6，ESP-Hosted SDIO Slot 1，4-bit 25 MHz |
| 音频 | ES8311，I2S0，16-bit stereo |
| 电池 | GPIO52 / ADC2 Channel 3，68k/100k 分压 |

## 显示时序

水平同步/后沿/前沿为 `40/160/160`，垂直同步/后沿/前沿为 `10/23/12`。54 MHz 像素时钟对应约 60.49 Hz。当前参数来自 JC1060P470 综合测试工程，但迁移后的 UI 和网络并发负载不同，仍需重新观察白条、闪屏、撕裂和 cache 一致性。

## 资源所有权

- `jc1060p470_bsp` 唯一拥有显示、触摸、共享 I2C、I2S codec 和 Hosted 初始化。
- GT911 与 ES8311 共享 I2C1，禁止业务层重复创建总线。
- 共享 I2C1 使用板级引用计数；显示和音频失败清理不得释放对方仍在使用的总线。
- Hosted 使用 SDIO Slot 1；本工程当前不使用 SD 卡，后续增加 SDMMC 功能时必须评估 controller 共存。
- 显示仅支持 0°/180°，两种方向都保持 1024x600，不交换横纵分辨率。

## 电池限制

当前电量按 3300 mV=0%、4200 mV=100% 线性计算，16 次采样平均。板上尚无已验证的 VBUS 或充电状态输入，因此 `external_power_known=false`、`charging=false`，软件不根据电池是否存在反推 USB 状态，也不会据此启用纯电池关屏策略。真机校准前该结果仅用于联调，不应作为准确电量计。
